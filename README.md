# AniSocBot
Discord bot for an anime societies point tracking needs.

## About
This is a python discord bot I created to use for tracking points in a society, it uses discord.py and a sqlite database.

I have tried to comment this the best I can in case any future committee or other society wants to use it, if you need any help contact me on discord @baguettewoman
